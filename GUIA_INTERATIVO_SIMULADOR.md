## 🕹️ 4. Guia de Comandos do Simulador

O simulador funciona como uma "caixa de areia" matemática. Digite os comandos abaixo na caixa de texto e veja a mágica acontecer!

### 📍 Criando Pontos e Vetores
*   **Ponto (Um local fixo):** Use letra MAIÚSCULA.
    *   Comando: `A = (2, 3, 1)`
*   **Vetor (Uma seta com direção):** Use letra minúscula.
    *   Comando: `v = (1, 1, 4)`

### 📏 Retas e Planos (As Estradas do Espaço)
*   **Reta:** Um ponto de partida mais uma direção multiplicada pelo tempo (t).
    *   Comando: `r = (0, 0, 0) + t(1, 1, 1)`
*   **Plano:** Uma parede infinita definida por uma equação.
    *   Comando: `x + y + z - 2 = 0`

### 🔮 Formas 3D (Cônicas e Quádricas)
*   **Esfera:** `esfera(raio)` -> Ex: `esfera(3)`
*   **Elipsoide (Ovo):** `elipsoide(largura, altura, profundidade)` -> Ex: `elipsoide(4, 2, 2)`
*   **Paraboloide (Taça):** `paraboloide(1, 1)`

## 🛠️ 5. Operações Mágicas (Modo Avançado)
Você pode fazer cálculos entre os objetos que já criou usando o número deles na lista:
1. `dot 1 2` -> Calcula o **Produto Escalar** (o quanto eles apontam para o mesmo lado).
2. `vetorial 1 2` -> Cria um novo vetor que é **perpendicular** aos dois originais.
3. `dist(A, B)` -> Mede a distância exata entre dois pontos e desenha uma linha guia.

## 🎁 6. Desafio MatrixLab: Arte Geométrica! 🏆

Use seus conhecimentos de coordenadas para "desenhar" objetos no espaço 3D. Complete um dos desenhos abaixo e mostre ao seu professor para ganhar sua recompensa!

### 🗼 Missão 1: A Antena de Transmissão
> Crie uma base no chão (plano XY) e uma antena que aponte para o espaço.
> 1.  `A = (1, 1, 0)`
> 2.  `B = (-1, 1, 0)`
> 3.  `C = (0, -1, 0)`
> 4.  `topo = (0, 0, 4)`
> **Desafio:** Use o comando `dist` para conectar cada ponto da base ao `topo`. O que você construiu?

### 📦 Missão 2: O Esqueleto do Cubo
> Use vetores para desenhar as três arestas principais de um cubo partindo da origem.
> 1.  `v1 = (2, 0, 0)`
> 2.  `v2 = (0, 2, 0)`
> 3.  `v3 = (0, 0, 2)`
> **Desafio:** Use o comando `soma 1 2` para criar a diagonal da base e depois some o resultado com o vetor 3. Onde a ponta do novo vetor vai parar?

### 🛸 Missão 3: Estação Espacial Matrix
> Vamos criar uma estrutura complexa misturando formas e vetores.
> 1.  `esfera(2)` (O núcleo da estação)
> 2.  `v1 = (5, 0, 0)` ; `v2 = (-5, 0, 0)` (Os braços de comunicação)
> 3.  `elipsoide(1, 1, 5)` (O suporte central)
> **Desafio:** Adicione um **plano** que represente o escudo de energia da estação e tire um print da sua criação!
