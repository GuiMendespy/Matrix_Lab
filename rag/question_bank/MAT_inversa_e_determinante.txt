ID: MAT-001
TOPICO: Matrizes
SUBTOPICO: Determinante e Matriz Inversa
DIFICULDADE: basico

ENUNCIADO:
Considere a matriz:

A = [ 2  1 ]
[ 5  3 ]

Determine:
a) o determinante da matriz A
b) a matriz inversa de A, caso exista

ALTERNATIVAS:
A) det(A) = 1 e A⁻¹ = [ 3  -1 / -5  2 ]
B) det(A) = 2 e A⁻¹ não existe
C) det(A) = 1 e A⁻¹ não existe
D) det(A) = 11 e A⁻¹ = [ 3  -1 / -5  2 ]

RESPOSTA_CORRETA: A

RESOLUCAO:
Para resolver este problema, precisamos primeiro calcular o determinante da matriz de ordem 2x2. Caso o determinante seja diferente de zero, a matriz possui inversa, a qual é calculada pela fórmula: A⁻¹ = (1 / det(A)) x [ d  -b / -c  a ], para uma matriz genérica com linhas [a b] e [c d].

Dados:
Matriz A:
[ 2  1 ]
[ 5  3 ]

Onde:
a = 2, b = 1, c = 5, d = 3

Passo 1: Calcular o determinante de A:
O determinante de uma matriz 2x2 é dado pelo produto dos elementos da diagonal principal menos o produto dos elementos da diagonal secundária.

det(A) = (a x d) - (b x c)
det(A) = (2 x 3) - (1 x 5)
det(A) = 6 - 5
det(A) = 1

Como det(A) = 1 (diferente de zero), a matriz inversa A⁻¹ existe.

Passo 2: Calcular a matriz inversa A⁻¹:
Para encontrar a matriz inversa de uma matriz 2x2, trocamos os elementos da diagonal principal de lugar (a com d) e invertemos o sinal dos elementos da diagonal secundária (b e c). Depois, multiplicamos a matriz resultante pelo inverso do determinante (1 / det(A)).

Matriz modificada:
[ 3  -1 ]
[ -5  2 ]

Aplicando a multiplicação pelo inverso do determinante (1 / 1):
A⁻¹ = (1 / 1) x [ 3  -1 ]
[ -5  2 ]

Como o multiplicador é 1, os elementos permanecem iguais:
A⁻¹ = [ 3  -1 ]
[ -5  2 ]

Representando em linha única para as alternativas: [ 3  -1 / -5  2 ]

Comparando com as alternativas:
Alternativa A: det(A) = 1 e A⁻¹ = [ 3  -1 / -5  2 ]

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é A.
