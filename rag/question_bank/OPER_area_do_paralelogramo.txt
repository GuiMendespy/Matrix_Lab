TEMA: Area do Paralelogramo via Produto Vetorial

ID: OPER-005
TOPICO: Vetores
SUBTOPICO: Produto Vetorial e Módulo
DIFICULDADE: basico

ENUNCIADO:
Determine a área do paralelogramo definido pelos vetores tridimensionais u = (2, 0, 0) e v = (0, 3, 0).

ALTERNATIVAS:
A) Área = 5 u.a.
B) Área = 0 u.a.
C) Área = 6 u.a.
D) Área = √13 u.a.

RESPOSTA_CORRETA: C

RESOLUCAO:
Geometricamente, a área de um paralelogramo determinado por dois vetores u e v é numericamente igual ao módulo do produto vetorial entre eles: Área = |u x v|.

Dados:
u = (2, 0, 0)
v = (0, 3, 0)

Passo 1: Calcular o produto vetorial (u x v):
Componente i: (0 x 0) - (0 x 3) = 0
Componente j: -((2 x 0) - (0 x 0)) = 0
Componente k: (2 x 3) - (0 x 0) = 6 - 0 = 6

Logo, o vetor do produto vetorial é:
u x v = (0, 0, 6)

Passo 2: Calcular o módulo do vetor resultante:
|u x v| = √(0² + 0² + 6²)
|u x v| = √36
|u x v| = 6

Portanto, a área do paralelogramo é 6 unidades de área (u.a.).

Comparando com as alternativas:
Alternativa C: Área = 6 u.a.

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é C.
