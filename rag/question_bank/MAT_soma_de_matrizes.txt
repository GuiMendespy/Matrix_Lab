ID: MAT-002
TOPICO: Matrizes
SUBTOPICO: Operacoes Basicas com Matrizes
DIFICULDADE: basico

ENUNCIADO:
Dadas as matrizes de ordem 2x2:

A = [ 1  3 ]     B = [ 4  -1 ]
[ 2  5 ]         [ 0   2 ]

Determine a matriz resultante da soma A + B.

ALTERNATIVAS:
A) A + B = [ 5  4 / 2  3 ]
B) A + B = [ 5  2 / 2  7 ]
C) A + B = [ 4  2 / 2  10 ]
D) A + B = [ 5  2 / 0  7 ]

RESPOSTA_CORRETA: B

RESOLUCAO:
A soma de duas matrizes de mesma ordem é realizada somando-se os elementos que ocupam a mesma posição (mesma linha e mesma coluna) em cada uma delas.

Dados:
Matriz A: [ 1  3 / 2  5 ]
Matriz B: [ 4  -1 / 0  2 ]

Aplicando a soma elemento a elemento:

Linha 1, Coluna 1:
1 + 4 = 5

Linha 1, Coluna 2:
3 + (-1) = 2

Linha 2, Coluna 1:
2 + 0 = 2

Linha 2, Coluna 2:
5 + 2 = 7

Organizando os resultados na matriz final:
A + B = [ 5  2 ]
[ 2  7 ]

Representando em linha única para as alternativas: [ 5  2 / 2  7 ]

Comparando com as alternativas:
Alternativa B: [ 5  2 / 2  7 ]

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é B.
