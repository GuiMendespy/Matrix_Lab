ID: VET-001
TOPICO: Vetores
SUBTOPICO: Produto Vetorial e Módulo
DIFICULDADE: basico

ENUNCIADO:
Considere os vetores tridimensionais:

a = (1, 2, 3)
b = (2, 1, 0)

Calcule:
a) o produto vetorial a x b
b) o módulo do vetor resultante

ALTERNATIVAS:
A) a x b = (-3, 6, -3) e |a x b| = 3√6
B) a x b = (-3, 6, -3) e |a x b| = √54
C) a x b = (3, -6, 3) e |a x b| = 3√6
D) a x b = (-3, 6, -3) e |a x b| = 6√3

RESPOSTA_CORRETA: A

RESOLUCAO:
O produto vetorial entre dois vetores tridimensionais resulta em um novo vetor perpendicular a ambos. Ele pode ser calculado através do determinante de uma matriz contendo os vetores unitários (i, j, k) na primeira linha e as coordenadas dos vetores dados nas linhas seguintes. O módulo do vetor resultante é calculado tirando a raiz quadrada da soma das componentes ao quadrado.

Dados:
a = (1, 2, 3)
b = (2, 1, 0)

Passo 1: Calcular as componentes do produto vetorial (a x b):

Componente i (coordenada x):
(2 x 0) - (3 x 1) = 0 - 3 = -3

Componente j (coordenada y - lembrando de inverter o sinal do determinante menor):
-((1 x 0) - (3 x 2)) = -(0 - 6) = 6

Componente k (coordenada z):
(1 x 1) - (2 x 2) = 1 - 4 = -3

Logo, o vetor resultante do produto vetorial é:
a x b = (-3, 6, -3)

Passo 2: Calcular o módulo do vetor resultante |a x b|:
|a x b| = √((-3)² + 6² + (-3)²)
|a x b| = √(9 + 36 + 9)
|a x b| = √54

Simplificando a raiz quadrada de 54:
54 = 9 x 6
√54 = √9 x √6 = 3√6

Logo:
a x b = (-3, 6, -3) e |a x b| = 3√6

Comparando com as alternativas:
Alternativa A: a x b = (-3, 6, -3) e |a x b| = 3√6

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é A.
