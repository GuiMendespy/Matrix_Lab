ID: MAT-003
TOPICO: Matrizes
SUBTOPICO: Multiplicacao de Matrizes
DIFICULDADE: basico

ENUNCIADO:
Considere as matrizes:

A = [ 2  1 ]     B = [ 1 ]
[ 3  4 ]         [ 2 ]

Determine a matriz produto C = A x B.

ALTERNATIVAS:
A) C = [ 2 / 8 ]
B) C = [ 4 / 7 ]
C) C = [ 3 / 11 ]
D) C = [ 4 / 11 ]

RESPOSTA_CORRETA: D

RESOLUCAO:
A multiplicação de matrizes é feita multiplicando-se as linhas da primeira matriz pelas colunas da segunda matriz. Cada elemento resultante é a soma dos produtos correspondentes.

Dados:
Matriz A (2x2): linhas [2 1] e [3 4]
Matriz B (2x1): coluna [1] e [2]

Calculando os elementos da matriz C:

Elemento da Linha 1, Coluna 1 (Linha 1 de A x Coluna 1 de B):
(2 x 1) + (1 x 2) = 2 + 2 = 4

Elemento da Linha 2, Coluna 1 (Linha 2 de A x Coluna 1 de B):
(3 x 1) + (4 x 2) = 3 + 8 = 11

Organizando os resultados na matriz final C:
C = [ 4 ]
[ 11 ]

Representando em linha única para as alternativas: [ 4 / 11 ]

Comparando com as alternativas:
Alternativa D: [ 4 / 11 ]

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é D.
