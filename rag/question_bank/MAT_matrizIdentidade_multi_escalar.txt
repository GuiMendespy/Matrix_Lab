ID: MAT-005
TOPICO: Matrizes
SUBTOPICO: Operacoes Basicas com Matrizes
DIFICULDADE: basico

ENUNCIADO:
Seja I a matriz identidade de ordem 2x2. Determine a matriz resultante da operação 3I.

ALTERNATIVAS:
A) 3I = [ 3  3 / 3  3 ]
B) 3I = [ 3  0 / 0  3 ]
C) 3I = [ 1  0 / 0  1 ]
D) 3I = [ 3  0 / 0  1 ]

RESPOSTA_CORRETA: B

RESOLUCAO:
A matriz identidade I de ordem 2x2 possui os elementos da diagonal principal iguais a 1 e os demais elements iguais a 0. A multiplicação de uma matriz por um escalar consiste em multiplicar cada elemento da matriz por esse número.

Dados:
Matriz Identidade I (2x2):
[ 1  0 ]
[ 0  1 ]

Multiplicando cada elemento pelo escalar 3:

Linha 1, Coluna 1: 3 x 1 = 3
Linha 1, Coluna 2: 3 x 0 = 0
Linha 2, Coluna 1: 3 x 0 = 0
Linha 2, Coluna 2: 3 x 1 = 3

Organizando a matriz final:
3I = [ 3  0 ]
[ 0  3 ]

Representando em linha única para as alternativas: [ 3  0 / 0  3 ]

Comparando com as alternativas:
Alternativa B: [ 3  0 / 0  3 ]

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é B.
