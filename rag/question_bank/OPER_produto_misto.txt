ID: OPER-007
TOPICO: Vetores
SUBTOPICO: Produto Misto
DIFICULDADE: basico

ENUNCIADO:
Calcule o produto misto [u, v, w] entre os vetores u = (2, 0, 0), v = (0, 1, 0) e w = (0, 0, 3).

ALTERNATIVAS:
A) [u, v, w] = 0
B) [u, v, w] = 5
C) [u, v, w] = 6
D) [u, v, w] = 2

RESPOSTA_CORRETA: C

RESOLUCAO:
O produto misto de três vetores, indicado por [u, v, w], é um valor escalar obtido pelo determinante da matriz 3x3 formada pelos três vetores dispostos em linhas. Alternativamente, ele equivale ao produto escalar do primeiro vetor pelo produto vetorial dos outros dois: u · (v x w).

Dados:
u = (2, 0, 0)
v = (0, 1, 0)
w = (0, 0, 3)

Passo 1: Montar a matriz 3x3 com os vetores em linhas:
[ 2  0  0 ]
[ 0  1  0 ]
[ 0  0  3 ]

Passo 2: Calcular o determinante da matriz:
Como esta é uma matriz diagonal (todos os elementos fora da diagonal principal são zero), o determinante é simplesmente o produto dos elementos da diagonal principal.

det = 2 x 1 x 3
det = 6

Logo, o produto misto [u, v, w] é igual a 6.

Comparando com as alternativas:
Alternativa C: [u, v, w] = 6

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é C.
