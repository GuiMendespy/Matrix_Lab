ID: VET-007
TOPICO: Vetores
SUBTOPICO: Produto Vetorial e Módulo
DIFICULDADE: basico

ENUNCIADO:
Determine o produto vetorial a x b entre os vetores da base canônica a = (1, 0, 0) e b = (0, 1, 0).

ALTERNATIVAS:
A) a x b = (1, 1, 0)
B) a x b = (0, 0, 0)
C) a x b = (0, 0, 1)
D) a x b = (0, 1, 0)

RESPOSTA_CORRETA: C

RESOLUCAO:
Geometricamente, o produto vetorial entre os dois primeiros vetores unitários da base canônica (i e j) resulta no terceiro vetor unitário (k), que é perpendicular a ambos. Podemos confirmar calculando as componentes do determinante menor.

Dados:
a = (1, 0, 0) -> vetor i
b = (0, 1, 0) -> vetor j

Calculando as componentes do vetor resultante (a x b):

Componente i:
(0 x 0) - (0 x 1) = 0 - 0 = 0

Componente j:
-((1 x 0) - (0 x 0)) = 0

Componente k:
(1 x 1) - (0 x 0) = 1 - 0 = 1

Logo, o vetor resultante é:
a x b = (0, 0, 1) -> vetor k

Comparando com as alternativas:
Alternativa C: (0, 0, 1)

Este é exatamente o resultado encontrado.

Portanto, a alternativa correta é C.
