TOPICO: Transformações Lineares
SUBTOPICO: Autovalores e Autovetores

DEFINICAO:
Seja T: V → V um operador linear. Um autovetor é um vetor não nulo que, após a transformação, mantém sua direção original, sendo apenas escalonado por um fator λ.

T(v) = λ.v

Onde:
- v é o autovetor (vetor não nulo)
- λ é o autovalor (escalar correspondente)

INTERPRETACAO GEOMETRICA:
O autovalor λ define o que acontece com o comprimento e o sentido do vetor:

- |λ| > 1: Dilatação
- |λ| < 1: Contração
- λ < 0: Inverte o sentido
- λ = 1: Identidade (vetor fixo)

AUTOVALORES DE UMA MATRIZ:
Para uma matriz quadrada A, os autovetores são soluções não triviais da equação matricial:

A.v = λ.v
(A - λI).v = 0

Para que essa equação tenha solução não trivial, o determinante deve ser zero:
det(A - λI) = 0

Essa equação é chamada de equação característica de A.

CASO ESPECIAL — MATRIZ DIAGONAL:
Para uma matriz diagonal D, os autovalores são os próprios elementos da diagonal principal, e os autovetores são os vetores da base canônica.

D = [ d1  0  ]   →   λ1 = d1, λ2 = d2
    [ 0   d2 ]
