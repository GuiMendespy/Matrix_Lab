TOPICO: Transformações Lineares
SUBTOPICO: Isomorfismos

DEFINICAO:
Um isomorfismo é uma transformação linear T: V → W que é bijetora (injetora e sobrejetora simultaneamente). Quando tal transformação existe, dizemos que os espaços V e W são isomorfos.

T é isomorfismo se:
- T é injetora: Nu(T) = {0}
- T é sobrejetora: Im(T) = W

PROPRIEDADES IMPORTANTES:
1. Dois espaços de dimensão finita são isomorfos se, e somente se, suas dimensões são iguais.
2. Se T é um isomorfismo, então o determinante de sua matriz associada é diferente de zero.

EXEMPLO:
Considere T: IR2 → IR2 definida por T(x, y) = (2x + y, 3x + 2y).

Para verificar se é isomorfismo, analisamos o núcleo:
T(x, y) = (0, 0)
2x + y = 0
3x + 2y = 0

Da primeira equação: y = -2x
Substituindo na segunda: 3x + 2(-2x) = 3x - 4x = -x = 0  →  x = 0  →  y = 0

Nu(T) = {(0, 0)}, portanto T é injetora.
Como dim(IR2) = dim(IR2) e T é injetora, T também é sobrejetora.
Logo, T é um isomorfismo.
