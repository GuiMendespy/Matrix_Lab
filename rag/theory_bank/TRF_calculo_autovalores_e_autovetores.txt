TOPICO: Transformações Lineares
SUBTOPICO: Cálculo de Autovalores e Autovetores

EQUACAO CARACTERISTICA:
Para encontrar autovalores de forma prática, transformamos a equação fundamental em um sistema homogêneo onde o determinante deve ser nulo para garantir soluções não triviais.

A.v = λ.v
(A - λI).v = 0
det(A - λI) = 0

POLINOMIO CARACTERISTICO:
O determinante det(A - λI) resulta em um polinômio de grau n, cujas raízes são os autovalores da matriz.

Para uma matriz 2x2:
A = [ a  b ]
    [ c  d ]

det(A - λI) = det([ a-λ  b  ]) = (a-λ)(d-λ) - bc = 0
                  ([ c    d-λ ])

Expandindo:
λ² - (a+d)λ + (ad - bc) = 0

As raízes λ1 e λ2 dessa equação são os autovalores de A.

SUBESPACOS PROPRIOS (AUTOVETORES):
Para cada autovalor encontrado, resolvemos o sistema (A - λI).v = 0 para encontrar os vetores associados.

Passos:
1. Calcular det(A - λI) = 0 para encontrar os autovalores λ1, λ2, ..., λn.
2. Para cada autovalor λi, substituir em (A - λiI).v = 0.
3. Resolver o sistema homogêneo para encontrar os autovetores associados a λi.

OBSERVACAO:
O conjunto de todos os autovetores associados a um autovalor λi, junto com o vetor nulo, forma um subespaço chamado subespaço próprio associado a λi.
