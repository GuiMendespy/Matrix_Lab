TOPICO: Transformações Lineares
SUBTOPICO: Operadores Diagonalizáveis

DEFINICAO:
Dizemos que um operador linear T é diagonalizável se existe uma base de V composta exclusivamente por autovetores de T. Nessa base, a matriz do operador assume uma forma diagonal.

D = [ λ1  0   0  ]
    [ 0   λ2  0  ]
    [ 0   0   λ3 ]

Onde λ1, λ2, λ3 são os autovalores de T.

CRITERIO DE DIAGONALIZACAO:
Um operador de ordem n é diagonalizável se, e somente se, ele possui n autovetores linearmente independentes (LI).

Equivalentemente, T é diagonalizável se a soma das dimensões dos subespaços próprios for igual a n:

dim(V1) + dim(V2) + ... + dim(Vk) = n

Onde Vi é o subespaço próprio associado ao autovalor λi.

EXEMPLO — OPERADOR NAO DIAGONALIZAVEL:
Nem todo operador é diagonalizável. Quando o polinômio característico possui raízes repetidas, pode ocorrer que não existam autovetores LI suficientes para formar uma base do espaço.

Neste caso, a soma das dimensões dos subespaços próprios é menor que n, e T não pode ser diagonalizado.

OBSERVACAO:
Se uma matriz de ordem n possui n autovalores distintos, então ela é sempre diagonalizável.
