TOPICO: Espaços Vetoriais
SUBTOPICO: Base e Dimensão

BASE:
Um conjunto B = {v1, v2, ..., vn} é uma base de um espaço vetorial V se atender a dois requisitos fundamentais simultaneamente:
1. B é linearmente independente (LI).
2. B gera V, ou seja, todo vetor de V pode ser escrito como combinação linear dos vetores de B.

BASE CANONICA:
A base mais simples do IRn é a canônica, formada pelos vetores unitários sobre os eixos coordenados.

Para IR2: e1 = (1, 0) e e2 = (0, 1)
Para IR3: e1 = (1, 0, 0), e2 = (0, 1, 0) e e3 = (0, 0, 1)

DIMENSAO:
A dimensão de um espaço vetorial V é o número de vetores de qualquer uma de suas bases. Se a base possui n vetores, dizemos que o espaço tem dimensão n.

Exemplos:
- dim(IR2) = 2
- dim(IR3) = 3
- dim(IRn) = n
