TOPICO: Vetores
SUBTOPICO: Superfícies Quádricas

DEFINICAO:
Uma superfície quádrica é o lugar geométrico dos pontos P(x, y, z) cujas coordenadas satisfazem a equação geral do 2° grau em três variáveis:

ax² + by² + cz² + dxy + exz + fyz + gx + hy + iz + j = 0

TRACO:
A interseção de uma superfície com um plano é chamada de traço. Se seccionarmos uma quádrica por planos paralelos aos planos coordenados, a curva resultante será sempre uma cônica.

QUADRICAS DEGENERADAS:
Existem casos onde a equação pode representar pontos, retas ou o conjunto vazio, conhecidos como quádricas degeneradas.

FORMAS CANONICAS CENTRADAS:

1. ELIPSOIDE:
x²/a² + y²/b² + z²/c² = 1

Elementos:
- Centro na origem
- Semieixos a, b e c ao longo dos eixos x, y e z
- Caso especial: se a = b = c, a superfície é uma esfera de raio a

2. HIPERBOLOIDE DE UMA FOLHA:
x²/a² + y²/b² - z²/c² = 1

Elementos:
- Superfície conexa (uma peça só)
- Traços horizontais são elipses
- Traços verticais são hipérboles

3. HIPERBOLOIDE DE DUAS FOLHAS:
x²/a² - y²/b² - z²/c² = 1

Elementos:
- Superfície em duas partes separadas
- Traços horizontais são elipses (quando existem)
- Traços verticais são hipérboles
